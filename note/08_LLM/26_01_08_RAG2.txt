벡터DB
	문자를 임베딩한 경우 이를 저장을 할 데이터베이스(벡터 스토어)가 필요
	ChromaDB
		인메모리 vector DB, 로컬 vector DB
			로컬 메모리에 sqlite로 저장
	Pinecone 
		클라우드 vector DB
		https//www.pinecone.io에서 api 키를 발급받아야함
Langchain을 이용한 RAG
	1. 문서를 읽는다
	2. 문서를 쪼갠다(langchain_text_splitters)
		TokenTextSplitter : 토큰수로 나누기
		RecursiveCharacterTextSplitter : 글자수로 나누기
	3. 쪼갠 문서를 임베딩하여 vector database에 넣음 (local에 저장) cf. 클라우드에 저장
	4. 질문을 이용해 유사도 검색
	5. 유사도 검색한 문서를 LLM에 질문과 함께 전달하여 답변 얻음 (랭체인 사용 가능)
